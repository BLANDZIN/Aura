# ◈ Welcome to AURA

AURA is not just another chatbot.

It is an attempt to create a **personal artificial intelligence companion** capable of living inside your computer, understanding your workflow, remembering important information and evolving alongside you.

Inspired by futuristic assistants like JARVIS, AURA combines:

- Artificial intelligence
- Persistent memory
- Personalization
- Desktop interaction
- Modular architecture
- Local AI models

into a single intelligent ecosystem.


> "A tool is controlled by the user.
> A companion grows with the user."


---

# 🧠 The Vision

Most AI assistants forget.

Every conversation starts from zero.

AURA was created with a different philosophy:

**An AI should remember.**

It should understand context, adapt its personality, store meaningful information and become more useful over time.


The goal is not to replace humans.

The goal is to **amplify human capability.**

# 🧠 Memory System

AURA uses a multi-layer memory architecture.


## Temporary Memory

Short-term context.

Used for:

- Current conversations
- Temporary tasks
- Recent interactions


## Permanent Memory

Important information that should persist.

Examples:

- User preferences
- Important facts
- Long-term context


## Procedural Memory

Patterns and learned behaviors.

Used for:

- Improving workflows
- Understanding habits
- Automation


```
Experience
     ↓
Classification
     ↓
Importance Analysis
     ↓
Memory Storage
     ↓
Future Intelligence
```

# 📦 Installation


Clone the repository:


```bash
git clone https://github.com/BLANDZIN/Aura

cd Aura
```


Create environment:


```bash
python -m venv aura_env
```


Activate:


Linux:

```bash
source aura_env/bin/activate
```


Windows:

```bash
aura_env\Scripts\activate
```


Install dependencies:


```bash
pip install -r requirements.txt
```


Run:


```bash
python main.py
```
